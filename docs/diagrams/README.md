# Diagramas

Hechos con [Archify](https://github.com/tt-a1i/archify) (MIT) a partir de los JSON de `src/`:

```sh
node <archify>/bin/archify.mjs finalize architecture src/forge-memory-en.json forge-memory.en.html --quality showcase
node <archify>/bin/archify.mjs finalize workflow src/project-guard-en.json project-guard.en.html --quality showcase
```

El PNG es una captura del HTML en tema oscuro (`?theme=dark`), a 960 px de ancho y 2×.
